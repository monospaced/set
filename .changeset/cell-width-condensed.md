Publish `typography.metric.default.cell.widthCondensed`, the character advance at the narrowest font width (0.45em in mnsp, 0.6em in wrfr, which has no width axis). With the existing cell width and ultra-condensed width tokens it gives the advance at any width as a straight line, for fit-to-width type.
