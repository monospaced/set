Add `@monospaced/set-react-native`: React Native components for Set,
sharing tokens via `@monospaced/set-tokens/react-native/<brand>`. Ships
`SetProvider` (resolves tokens for colour scheme and window size),
`Surface` (surface context and pinned scheme), `useSetTokens`, and the
first components: `Icon` (the `@monospaced/set-icons` registry via `react-native-svg`),
`Button` and `Avatar`.
