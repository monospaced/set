Grid gains `responsiveRowGap`: `md`, `lg` or `xl` on the responsive vertical spacing scale. It overrides the row axis of `gap` when set, so a grid of page sections keeps the page's section spacing once its columns stack on narrow screens.

The package index also exports the remaining prop unions: `SetIconName`, `SetInlineAs`, `SetMenuAlign`, `SetNavCollapsible`, `SetNavExpanderPosition`, `SetNavSize` and `SetStackAs`.
