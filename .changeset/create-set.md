New package. `pnpm create @monospaced/set my-site` scaffolds a Vite + TypeScript site built from Set components, with the head hygiene of the Set docs, the config package's ESLint and Stylelint presets, Lightning CSS targets from Set's Baseline query, Prettier, Husky and lint-staged, VS Code settings, agent skills, a sync script that refreshes Set artifacts on install, and an initial commit. Dependencies install live; tools the config package declares as peers install at its declared ranges. Prompts for package name, title and description, each with a flag, and `--defaults` to take every default.
