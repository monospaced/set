Commit here, commit there, then answer

A write is acknowledged only when both sides hold it. Antipode sends each commit down the shortest fibre path to the far side and waits for the echo.

  • Synchronous by default
  • Per-table opt-out to async
  • One sequence, no conflicts
  • Speaks Postgres, MySQL and SQLite

The nearest healthy side answers

Requests enter at the closer site of each pair. If that site stops answering, the far side takes its traffic within one health check: 40 ms.
